# Gambar pemain Sabah FC

Upload gambar pemain dalam folder ini dalam format PNG, menggunakan **nombor jersi sebagai nama fail**.

Contoh: `13.png` untuk pemain bernombor jersi 13. Gambar akan digunakan pada senarai pemain dan profil pemain. Gunakan foto potret nisbah 1:1 atau 3:4 dengan latar belakang lutsinar jika sesuai.

GitHub Pages akan memaparkan gambar kepada semua pelawat selepas commit dan deployment selesai. Jangan masukkan foto yang anda tiada hak untuk terbitkan.
