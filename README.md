# Sabah FC Fan Portal

Portal komuniti Sabah FC (tidak rasmi) untuk musim 2026/2027.

## Fungsi
- Home, Matches, Standing, Stats, Players, About
- Admin editor demo: tambah pemain dan perlawanan
- Kedudukan liga dikira daripada keputusan FULL TIME
- Simpanan localStorage per pelayar, export JSON
- Responsif desktop, tablet dan telefon

## Penerbitan
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

## Penting
Tiada pengesahan pengguna sebenar atau pangkalan data bersama. Data contoh tidak boleh dianggap rasmi. Jangan simpan kata laluan dalam fail frontend.

## Android TV / Google TV

Aplikasi paparan TV dan APK pemasangan terus tersedia dalam [android-tv](android-tv/README.md). Kawalan remote disokong; data portal dimuatkan daripada Cloudflare.

## Notifikasi kick-off telefon

Butang **Notifikasi** membolehkan pengguna melanggan peringatan kick-off mengikut
jadual admin. Pemasangan servis Cloudflare diperlukan untuk push ketika webapp
ditutup. Ikuti [panduan pemasangan notifikasi](docs/kickoff-notifications.md).
